Familiar by design

If you can write a skill, you can write a workflow.

A WORKFLOW.md is the same idea as a Claude Code skill: a markdown file with frontmatter and one heading per step. It lives in your session — no server, no Python, no extra services; it runs on the same Node that powers Claude Code. Agent Flow just adds the durable state and the deterministic control flow that turn those steps into a resumable pipeline.

SKILL.md

Frontmatter + instructions → Claude performs one capability, on demand.

WORKFLOW.md

Frontmatter + one heading per stage → a durable, resumable pipeline of those capabilities — composed and branched with code, checkpointed to disk.

// before

You kick off a 200-file review, a multi-chapter draft, a queue drained from three terminals. Then compaction hits at item 142 — the in-flight sub-agents take their state with them. No checkpoint, no resume. Hours gone.

// with agent flow

Each step is an LLM doing the work, but the control flow is deterministic and every run is a state.json on disk. A Stop hook auto-continues it across turns — surviving parallelism, interruption, and compaction. Resume at item 143.

What you get

A real vocabulary for orchestrating agents — on durable state.

You describe the goal in plain English; the engine writes the exact commands. Below is what runs under the hood.

01

Durable & resumable

Every run is a state.json with atomic writes; a Stop hook continues in-flight runs across turns and survives compaction. A second hook snapshots the chat too.

02

A programmatic vocabulary

enumerate · foreach · reduce · group · repeat/until/while · step — composed by pipe.

03

Workflows as readable markdown

Same shape as a SKILL.md — frontmatter + one heading per stage. Parameterize with --param, branch with fork, validate a step against a schema, nest sub-workflows.

04

Any runtime for a step

Run a prompt inline, in a subagent, or sessionlessly via claude -p / codex exec — the basis for cross-model conversations.

05

Scale safely

Split a list across terminals with --shard, or drain one lock-free queue from many workers (atomic-rename claim, no double-processing); coordinate via a mailbox.

06

Stay in control

Cost caps (--max-usd) pause a run. Many jobs at once? runs shows the queue (priority, then FIFO); runs pause freezes the whole engine, runs stop <id> just one — all non-destructive. board/inspect show cost & what's in flight.

07

Reuse without re-running

inspect results <run> dumps a finished run's outputs (--json / --checklist) so you transform an expensive run deterministically — no re-review.

Zero runtime dependencies

TypeScript compiled to a committed dist/; Node builtins only — no third-party npm packages. Apache-2.0.

fs · path · crypto · child_process
Why Agent Flow

It earns its keep when work fans out, loops, or runs long enough to risk interruption.

If your task is a single prompt, you don't need it — just ask Claude. Here's the honest comparison.

instead of plain sub-agents

The same agents, but with durable state — they resume across turns and survive compaction, composed with a real vocabulary instead of ad-hoc prompting.

instead of LangGraph / LangChain

No Python service, no runtime deps, no separate process — workflows live in your Claude Code session as readable, diffable markdown.

instead of Airflow / Prefect / Temporal

No server, no scheduler, no infra — durability is a state.json on disk, not a database.

In practice

You say it in plain language → Agent Flow runs it.

“Audit src for bugs and give me a report.”
/agentflow:audit --target src --file-glob "**/*.cs"
“Draft every chapter of this outline.”
enumerate outline → foreach draft → reduce stitch
“Keep fixing the build until it passes.”
/agentflow:until --stage "npm run build" --stop "npm run build"
“Chew through this list from 3 terminals.”
/agentflow:queue --items work.json --prompt "…" (×3)
“Review the diff; only deploy if it's safe.”
step emits {blocking} → fork routes to ship | fix
“Turn that finished review into a to-do list — don't re-run it.”
inspect results <run> --checklist > CHECKLIST.md
“Too much running — hold everything, I'll resume later.”
runs pause → runs resume
Get started

Two lines inside Claude Code.

claude code — installagentflow@agentflow
# inside Claude Code
/plugin marketplace add AleSaiani/agentflow
/plugin install agentflow@agentflow
